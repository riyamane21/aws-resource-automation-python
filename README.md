# AWS Resource Automation Using Python

## Project Overview
This project automates basic AWS resource management tasks using Python and the Boto3 AWS SDK.

## Technologies Used
- Python
- Boto3
- Amazon S3
- Amazon EC2

## Features
- List S3 buckets in an AWS account.
- List EC2 instances and their states.
- Upload a file to an Amazon S3 bucket.
- Use a menu-driven Python program to perform basic operations.

## Project Files
- `aws_automation.py` — Main automation program.
- `list_s3.py` — Lists S3 buckets.
- `list_ec2.py` — Lists EC2 instances.
- `test_aws.py` — AWS connection testing script.
- `sample.txt` — Sample file for upload testing.

## Prerequisites
- Python installed.
- An AWS account with appropriate permissions.
- Boto3 installed (`pip install boto3`).
- AWS credentials configured securely using an approved method.

## How to Run
1. Install Boto3.
2. Configure AWS credentials securely.
3. Open a terminal in the project folder.
4. Run `python aws_automation.py`.

## Security
Never upload AWS access keys, secret keys, passwords, or other sensitive credentials to GitHub.
